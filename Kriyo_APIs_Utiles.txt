Kriyo — 100 API utiles pour optimiser l'application
Genere le 2026-10-07. Classees par domaine fonctionnel, chacune avec le lien
direct vers son usage dans Kriyo (Sas de Securite, Score de Performance,
Tracking, Education, Admin, infra).

================================================================
A. DONNEES DE MARCHE & CALENDRIER MACRO
   (objective le critere "Macro" et "Alignment" du Sas de Securite,
   aujourd'hui bases sur de l'autodeclaration)
================================================================
1. TradingEconomics API — calendrier economique complet temps reel, pour
   automatiser la question "calendrier eco verifie du jour".
2. Forex Factory calendar — alternative gratuite de calendrier macro.
3. FRED (Federal Reserve Economic Data) API — donnees macro officielles US
   (taux, inflation) pour contextualiser les annonces a fort impact.
4. Finnhub — cours temps reel actions/forex/crypto + news, pour afficher le
   marche suivi dans l'ecran Tracking.
5. Alpha Vantage — cours historiques/temps reel gratuits, fallback simple
   pour petit volume d'utilisateurs.
6. Twelve Data — cours multi-actifs avec plan gratuit genereux, bon
   fallback secondaire.
7. Polygon.io — donnees de marche US temps reel qualite institutionnelle,
   si le volume d'utilisateurs augmente.
8. OANDA REST API — cours forex + spreads temps reel, pertinent car Kriyo
   cible des traders forex en prop firm.
9. Indice VIX (via Twelve Data/Alpha Vantage) — objective la question
   "volatilite actuelle dans ta plage acceptable" du critere Alignment.
10. Market Hours / Trading Sessions API (ex: Polygon Market Status) —
    savoir si Tokyo/London/NY est ouvert, pertinent pour Macro/Alignment.
